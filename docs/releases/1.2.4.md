OwnCord 1.2.4 исправляет ложную ошибку `UNKNOWN` при входе с сохранённой сессией.

- Автоматический вход теперь проверяет сохранённый токен по действительному адресу сервера `/api/v1/auth/me`. Ранее клиент обращался к отсутствующему `/api/v1/users/me`, получал 404 и сообщал об ошибке, хотя обычный вход по паролю продолжал работать.
- Если сервер возвращает 404 без кода ошибки, вместо `UNKNOWN` показывается понятное сообщение о неподдерживаемом запросе.
- На сайте «Запомнить вход» сохраняет токен сеанса для следующего входа. Браузер не сохраняет и не подставляет пароль в поле. В приложении Windows пароль при выборе «Запомнить пароль» хранится в диспетчере учётных данных Windows.

Проверено: модульные тесты API и ошибок, браузерное восстановление сохранённого сеанса и повторный вход после перезагрузки страницы. Браузерный сценарий отдельно возвращает 404 для прежнего неверного адреса, чтобы ошибка не повторилась.
