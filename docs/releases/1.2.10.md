# OwnCord 1.2.10

- Ползунок громкости демонстрации экрана изменяет уровень звука, а не только включает и выключает его. Уровень сохраняется отдельно для каждого пользователя и учитывает общую громкость вывода.
- Для каждой трансляции, включая собственную, появилась кнопка полноэкранного просмотра. Если браузер не поддерживает системный полноэкранный режим, трансляция разворачивается внутри приложения.
- В текстовых чатах аватар снова выровнен с регалией голосового времени.
