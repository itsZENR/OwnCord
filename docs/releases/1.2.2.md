OwnCord 1.2.2 исправляет отображение и запуск трансляций экрана.

- Экран показывается целиком с сохранением пропорций в сетке, развёрнутом просмотре и миниатюре. Края широких и вертикальных экранов больше не обрезаются ради заполнения рамки.
- Добавлена кнопка «Посмотреть свою трансляцию». Свой экран можно открыть, находясь в голосовом канале одному; доступен также предпросмотр при наведении на себя в списке участников. Звук собственного предпросмотра выключен.
- Исправлен порядок запуска: интерфейс сообщает о трансляции после готовности потока. Отмена выбора, ошибка публикации, выход из канала и остановка через системный индикатор освобождают захват и обновляют состояние.
- Для системного звука запрашивается исключение аудио OwnCord, чтобы голоса участников не возвращались через трансляцию. Результат проверяется до публикации звуковой дорожки. Если браузер/WebView2 не умеет исключать звук звонка, экран передаётся без системного звука с пояснением; звук отдельной вкладки браузера остаётся доступен.
- Режим исходного качества больше не получает скрытое ограничение захвата 1080p из LiveKit.

Системная плашка браузера/WebView2 остаётся: этот выпуск не заменяет системный захват нативным механизмом Windows. Исключение собственного звука зависит от поддержки браузера/WebView2; реальные сочетания звуковых устройств требуют проверки на устройстве пользователя.

Для исправления браузерной версии обновите сервер до 1.2.2 и перезагрузите страницу. В Windows обновите приложение до 1.2.2. Исправление эха применяется на стороне пользователя, который запускает трансляцию.

Проверено: 3000 модульных тестов, проверка типов, линтер и два браузерных сценария с широким и вертикальным источниками. Установщик `OwnCord_1.2.2_x64-setup.exe` и подпись для автообновления публикуются вместе с серверными бинарниками Windows/Linux и контрольными суммами.
