OwnCord 1.2.1 исправляет самопроизвольное выключение микрофона при вставке текста и включает обновления интерфейса, сохранения входа и голосового общения.

- Исправлен конфликт Push-to-Talk с Ctrl+V и другими сочетаниями клавиш. В браузере PTT теперь выключен по умолчанию, сохраняет выбранную клавишу и не срабатывает при вводе текста. В Windows сочетания с модификаторами также не активируют PTT.
- Под аватарами в чате, списке участников и голосовых каналах отображается общее голосовое время на сервере. Вкладка «Статистика» показывает время участников и рейтинг.
- Добавлены личные звонки: входящий вызов, принятие, отклонение и завершение. Личные звонки не увеличивают серверные часы.
- Исправлены сохранение входа, восстановление сеанса и повторное подключение. В браузере «Запомнить вход» сохраняет сеанс и включает автовход; в Windows пароль сохраняется в диспетчере учётных данных при выборе соответствующего флажка.
- Добавлены русский и английский языки для основных экранов входа и новых функций, понятные сообщения об ошибках подключения и голосовой связи.
- Исправлены состояния участников при переключении и выходе из голосовых каналов, обработка неудачного подключения и отображение времени сообщений.

Для исправления Ctrl+V в браузере обновите сервер до 1.2.1 и перезагрузите страницу. Для Windows установите приложение 1.2.1. Статистике и личным звонкам нужен сервер 1.2.0 или новее. Серверная миграция сохраняет существующие аккаунты и сообщения. Голосовое время накапливается с момента обновления сервера; история часов до обновления не восстанавливается.

Windows: установщик `OwnCord_1.2.1_x64-setup.exe`; рядом опубликована подпись для встроенного автообновления. Серверные бинарники для Windows и Linux amd64 включают веб-клиент. Контрольные суммы находятся в `checksums.sha256`.
