# OwnCord 1.2.8

- Перед загрузкой аватара открывается редактор с круглой областью обрезки. Фотографию можно передвинуть и увеличить; сохранится именно выбранная область.
- Аватары в чате и профиле отображаются круглыми, в том числе при показе регалии под аватаром.
- Для новых установок порог включения микрофона по умолчанию равен 0%: голос не отсекается. Ранее сохранённые настройки чувствительности не меняются.
