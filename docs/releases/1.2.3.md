OwnCord 1.2.3 разделяет текущие голосовые сессии и накопленную статистику.

- Рядом с каждым участником голосового канала отображается длительность его текущего подключения в формате ЧЧ:ММ:СС. Повторный вход или переход в другой канал начинает новый личный отсчёт.
- Рядом с названием занятого канала отображается длительность общей сессии: с первого подключения до момента, когда канал опустеет. Уход первого участника не сбрасывает общий таймер, пока в канале остаются другие люди.
- Отметки начала сессий передаются сервером при входе и обновлениях состояния. Показания учитывают разницу часов устройства и сервера. Таймеры обновляются каждую секунду без пересоздания строк участников и предпросмотров трансляций.
- Накопленные часы в отдельных каналах перенесены во вкладку «Статистика», в раскрывающийся блок «Накопленное время по каналам» у каждого участника. Суммарное время на сервере остаётся регалией под аватаром.

Для новых таймеров требуется сервер 1.2.3: обновите браузерную страницу или Windows-приложение после обновления сервера. При подключении нового клиента к старому серверу вместо неизвестного времени отображается «—». Перезапуск сервера завершает текущие подключения; накопленная статистика сохраняется.

Проверено: 3004 теста клиента, проверка типов и линтер, все тесты сервера, три браузерных сценария. Проверки включают независимые личные таймеры, общий отсчёт после ухода первого участника, переходы между каналами, разницу часов устройств и раскрытие накопленной статистики.
