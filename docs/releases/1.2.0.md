OwnCord 1.2.0 обновляет интерфейс, сохранение входа и голосовое общение.

- Под аватарами в чате, списке участников и голосовых каналах отображается общее голосовое время на сервере. Вкладка «Статистика» показывает время участников и рейтинг.
- Добавлены личные звонки: входящий вызов, принятие, отклонение и завершение. Личные звонки не увеличивают серверные часы.
- Исправлены сохранение входа, восстановление сеанса и повторное подключение. В браузере «Запомнить вход» сохраняет сеанс и включает автовход; в Windows пароль сохраняется в диспетчере учётных данных при выборе соответствующего флажка.
- Добавлены русский и английский языки для основных экранов входа и новых функций, понятные сообщения об ошибках подключения и голосовой связи.
- Исправлены состояния участников при переключении и выходе из голосовых каналов, обработка неудачного подключения и отображение времени сообщений.

Для статистики и личных звонков обновите сервер и приложения до 1.2.0. Серверная миграция сохраняет существующие аккаунты и сообщения. Голосовое время накапливается с момента обновления сервера; история часов до обновления не восстанавливается.

Windows: установщик `OwnCord_1.2.0_x64-setup.exe`; рядом опубликована подпись для встроенного автообновления. Серверные бинарники для Windows и Linux amd64 включают веб-клиент. Контрольные суммы находятся в `checksums.sha256`.
